# Heroes of Fright and Panic

Asynchronous turn-based strategy game for two players on a hexagonal grid.

Day and night factions take turns based on an in-game clock. Build settlements, gather resources, craft equipment, train armies, and defeat your opponent's king.

## Quick Start

```
nvm use
pnpm install
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) to play.
